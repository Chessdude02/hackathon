# Client profit finder

A tool for small agencies (5-30 staff). The owner uploads three CSV files
(invoices, time entries, client requests) and gets clients ranked by true
profit, a warning for clients heading toward a loss, and one recommended
action per client with its dollar effect. The owner makes every decision;
the tool never acts on its own.

Built for ForgeHacks Online 2026, Business track.

## Status

Work in progress. Today the repo holds the input schema, the data generator,
the hand-calculation check inputs and their tests. See `docs/execution.md`
for exactly what exists and how to run it, and `docs/decisions.md` for why.

## Quick start

```
pip install -r requirements.txt
python scripts/generate_data.py --out data/generated --seed 42
pytest
```

## About the data

No real client data is used. All data is generated by `generator/` with
planted patterns (clients that look large but lose money, slow payers, growing
scope creep, noise). Ranking and forecast results on this data show that the
code works. They do not show that it is accurate on real businesses.
